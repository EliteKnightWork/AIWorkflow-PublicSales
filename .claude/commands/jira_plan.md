# Jira チケット実装方針生成（jira_plan）

指定されたJiraチケットURLから内容を読み込み、実装方針を出力する

## 使用方法

```
/jira_plan <JIRA_TICKET_URL>
or
/jira_plan <JIRA_TICKET_KEY>
```

例:
```
/jira_plan https://labid.atlassian.net/browse/LABID-123
or
/jira_plan LABID-123
```

## 機能

- JiraチケットのURLからチケットキーを抽出
- MCPのJira統合を使用してチケット詳細を取得
- チケット内容を分析して実装方針を生成
- 関連するコードベース情報の参照

## ワークフロー

1. 引数として渡されたJiraチケットURLの形式を検証
2. URLからチケットキー（例: PROJ-123）を抽出
3. MCPのJira統合を使用してチケット詳細を取得
   - チケットのタイトル、説明、ステータス、優先度
   - 添付ファイル情報
   - コメント履歴
   - 関連チケット情報
4. プロジェクトのコードベース構造を分析
   - CLAUDE.mdの内容を参照
   - 関連するファイルやディレクトリを特定
5. チケット内容とコードベース情報を基に実装方針を生成
   - 要件の整理と分析
   - 影響範囲の特定
   - 実装手順の提案
   - 必要なテストの提案
   - 注意点とリスクの指摘

## 出力内容

### 1. チケット情報サマリー
- チケットキー
- タイトル
- ステータス
- 優先度
- 担当者
- 説明の要約

### 2. 要件分析
- 機能要件の整理
- 非機能要件の特定
- 受け入れ条件の明確化

### 3. 実装方針
- アーキテクチャ上の考慮事項
- 影響を受けるコンポーネント
- 実装すべきファイル・モジュール

### 4. 実装手順
- 段階的な実装ステップ
- 依存関係の整理
- 開発優先順位の提案

## 利用可能なMCPツール

- `mcp__atlassian__jira_get_issue`: チケット詳細の取得

## エラーハンドリング

- 無効なURLが指定された場合: URLの形式説明と例を表示
- チケットが見つからない場合: チケットキーの確認とアクセス権限の確認を促す
- MCPの接続エラー: Jira統合の設定確認を促す
