# GitHub CLI を利用したプルリクエスト作成

作業中のブランチのプルリクエストを作成

## 使用可能な GitHub CLI コマンド

- `gh pr create`: プルリクエストの作成(オプション指定可能)
- その他、Read系のコマンドは使用可能
- これ以外のリポジトリやファイルの変更等を行うコマンドは使用不可

## ワークフロー

1. 現在、作業中のブランチをユーザーに通知し、処理を開始
2. コミット前の変更があるかを確認し、ある場合は、ユーザーにこのまま続けていいかを確認
3. ブランチがプッシュされているかを確認し、プッシュされていない場合は、ユーザーに通知し、処理を中止
4. マージ先のブランチが `master` ブランチでいいかをユーザーに確認
5. リモートの現在のブランチとリモートのマージ先のブランチの差分を取得
6. 差分の内容を基に テンプレート(`.github/PULL_REQUEST_TEMPLATE.md`) に沿ったプルリクエストの本文を作成
7. タイトル・本文などを指定してプルリクエストを作成
8. 作成されたプルリクエストの url をユーザーに通知して、処理を終了

## 注意

- リポジトリやファイルの編集は絶対に行わないこと

## プルリクエストの本文について

- 本文の最後に、「このプルリクエストは Claude Code によって自動生成されました」と記述すること
